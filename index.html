О проекте

CACTUSTOOLS — это мощный консольный фреймворк, написанный на Python. Он объединяет в себе 18 утилит для работы с сетью, криптографией, системной информацией и генерацией данных. Всё это упаковано в стильный терминальный интерфейс с матричной загрузкой и фиолетовым градиентом.

Возможности

  • 18 инструментов в одном окне (пароли, хеши, UUID, Base64, сеть, шифры)
  • Матричная загрузка с глитч-эффектом и прогресс-барами
  • Градиентный ASCII-логотип с TrueColor поддержкой
  • Кроссплатформенность (Windows, Linux, macOS)
  • Компактный .exe файл, не требующий установленного Python

Установка из исходников

# 1. Клонировать репозиторий
git clone https://github.com/cactuspopov/CactusTUI.git

# 2. Перейти в папку
cd CactusTUI

# 3. Установить зависимости
pip install colorama

# 4. Запустить
python main.py

Сборка своего .exe

Хочешь собрать приложение сам? Используй PyInstaller:

pip install pyinstaller

python -m PyInstaller --onefile --name CACTUSTOOLS --hidden-import=colorama main.py

Готовый файл появится в папке dist/.
