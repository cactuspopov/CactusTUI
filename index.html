О проекте

CACTUSTUI — это мощный консольный комбайн, написанный на Python. Он объединяет в себе генератор паролей, хеширование, конвертацию Base64, работу с UUID, системную информацию и даже бросок кубиков D&D.

Возможности

  • 5 цветовых тем (включая культовую Cactus)
  • Плавная анимация интерфейса
  • Сохранение профиля в конфиг
  • 8 инструментов в одном окне

Установка и запуск

# Скачать репозиторий
git clone https://github.com/yourname/cactustui.git

# Запустить
cd cactustui && python main.py
